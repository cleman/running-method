What converged, what stayed open

Converged

  • Fixed rule tiers; safety first; fail closed with ranked options
  • Parameter registry: every number graded, schools as presets
  • Effort words before paces; paces only from measured results
  • No catch-up after missed sessions; single-run spike cap
  • Adaptation is re-measure and re-plan — never claimed to prevent injury

Settled late

  • OPEN-1: marathon long run 3 h / ~30 km default, optional extensions
  • OPEN-2: ultra caps per distance (50K 4 h, 100K 5 h 30) with distance floors
  • Never-runners: 9-week C25K start ladder
  • 65+: attestation before runs expected over 3 h

Still open

  • Contrarian: ultras should stay 'stretch' at the time cap; 50K aerobic level 3
  • First Principles: no 65+ gate (policy without comparative evidence)
  • Duration caps are coaching convention — pilot data needed
